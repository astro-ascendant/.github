# astro-ascendant/.github

Organization defaults for the [Astro Ascendant](https://github.com/astro-ascendant) account.

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Rendered on the organization Overview page at [github.com/astro-ascendant](https://github.com/astro-ascendant). |
| [`.github/FUNDING.yml`](.github/FUNDING.yml) | Sponsor links inherited by organization repositories that do not set their own. |

Nothing here ships to users. The libraries live in
[`ascendant-ts`](https://github.com/astro-ascendant/ascendant-ts),
[`ascendant`](https://github.com/astro-ascendant/ascendant), and
[`ascendant-agents`](https://github.com/astro-ascendant/ascendant-agents).
